# The Ultimate Android/Linux Hybrid Kernel Flags (Poco F7 / Snapdragon 8 Elite)

When you download the kernel source code for Infinity X, edit your device's `defconfig` file and ensure the following flags are set exactly as shown below:

# --- 1. System V IPC (Mandatory for Steam x86 and Native ARM64) ---
# Android natively disables System V IPC, which causes Steam to instantly crash.
# Whether using emulation or the new Native ARM64 Steam Client, Valve's core engine
# (specifically threadtools.cpp) relies strictly on SysV Semaphores (semget).
# This flag is the ONLY way to fix the `Assertion Failed: Function not implemented` crash.
CONFIG_SYSVIPC=y
CONFIG_SYSVIPC_SYSCTL=y
CONFIG_POSIX_MQUEUE=y

# --- 2. Binfmt Misc (For Transparent Emulation) ---
# Allows Linux to natively run x86/32-bit files using Box64 or FEX-Emu
CONFIG_BINFMT_MISC=y

# --- 3. Namespaces & Sandboxing (Mandatory for Steam/Systemd) ---
# Steam requires these to sandbox its web helper processes
CONFIG_NAMESPACES=y
CONFIG_USER_NS=y
CONFIG_PID_NS=y
CONFIG_NET_NS=y
CONFIG_UTS_NS=y
CONFIG_IPC_NS=y

# --- 4. Cgroups (For System Stability & Resource Management) ---
CONFIG_CGROUPS=y
CONFIG_CGROUP_FREEZER=y
CONFIG_CGROUP_DEVICE=y
CONFIG_CGROUP_CPUACCT=y
CONFIG_MEMCG=y

# --- 5. Networking & Virtual Interfaces (Optional but recommended) ---
CONFIG_MACVLAN=y
CONFIG_VETH=y
CONFIG_BRIDGE=y
CONFIG_TUN=y
