Adreno 5xx (e.g. A510) Support Notes

- Turnip/Zink won't work here. Turnip is hardcoded for Adreno 6xx+ architectures. The 500 series uses a completely different and older instruction set.
- Since Turnip fails, Zink has nothing to translate to, so we can't use it.
- Best fallback: VirGL.
- VirGL takes the Linux OpenGL calls and passes them to the host Android OS's native GLES drivers. It's stable and performs decently for older chips.

Setup instructions for testers:
1. Run `./setup.sh`
2. When prompted for GPU Architecture, pick Option 2: VirGL.
3. The script handles the rest (spins up `virgl_test_server` in termux, sets `GALLIUM_DRIVER=virpipe`, and binds the `.virgl_test` socket to the chroot).
