Adreno 6xx / 7xx / 8xx Support Notes

- These are the sweet spot for native hardware acceleration. Adreno 600 (SD845, 865, 870), 700 (SD8 Gen 1-3), and 8xx series are fully supported by Mesa Turnip.
- Stack: App OpenGL -> Zink -> Turnip (Vulkan) -> kgsl kernel driver.
- This gives us bare-metal performance inside the chroot, bypassing software emulation entirely. 

Setup instructions:
1. Run `./setup.sh` or run the GPU fixer (`./scripts/fix_gpu.sh`).
2. Pick Option 1: Zink (Vulkan to OpenGL).
3. The script pulls the pre-compiled `mesa-for-android-container` drivers and injects them natively. 
4. It also automatically applies the `MESA_VK_WSI_DEBUG=sw` fix so Termux:X11 doesn't crash on buffer swaps. 
- No VirGL needed, this runs pure native acceleration.
